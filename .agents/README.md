# Lumen Agent Instructions

This folder contains reusable instructions for Codex and other coding agents working on Lumen.

Use these files before making non-trivial changes:

- `codex.md` — baseline working style, code quality, and collaboration rules.
- `architecture.md` — repo structure, module boundaries, and data-flow expectations.
- `product-principles.md` — public-interest boundary and non-exploitation rules.
- `frontend.md` — UI direction, accessibility, and responsive design rules.
- `verification.md` — checks expected before handing work back.

The short version: keep Lumen public-interest, evidence-based, readable, and boringly reliable.
